# 🎂 Avalon20

**Avalon20** is a cinematic, interactive birthday website built with **Next.js**, combining storytelling, animations, 3D experiences, and personalized memories into a single immersive celebration.

Rather than being a traditional birthday webpage, Avalon20 is designed as an experience—guiding the recipient through multiple interactive sections filled with photos, effects, surprises, and heartfelt moments.

---

## ✨ Features

- 🔥 Interactive age reveal with realistic burn animation
- 🎈 Balloon celebration effects
- 📖 Animated scrapbook with page-flipping interactions
- 🖼️ Dynamic photo gallery
- 🌌 Interactive 3D photo galaxy (React Three Fiber)
- 🎮 Draggable photo cards with physics
- 🎨 Smooth transitions and motion animations
- 💖 Fully customizable with personal photos and messages
- 📱 Responsive design
- ⚡ Built with Next.js App Router

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/avalon20.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

---

## 🎨 Personalization

Avalon20 is designed to be easily personalized.

Replace the images inside:

```
public/ref/
```

Customize scrapbook assets inside:

```
public/pages/
public/frames/
public/elements/
```

Update captions, messages, and titles inside the React components to create a unique experience for the recipient.

## 📸 Main Sections

### 🔥 Hero

A cinematic age reveal featuring a realistic burning animation that transitions into the birthday celebration.

### 📖 Scrapbook

Interactive flipbook showcasing memories, photos, and handwritten-style notes.

### 🖼️ Photo Wall

A draggable collection of polaroid-style photographs.

### 🌌 Galaxy

A 3D floating gallery where memories orbit around the viewer.

### 🎈 Celebration

Balloon animations and visual effects complete the birthday experience.

---

## 🎯 Purpose

Avalon20 was created as a handcrafted digital birthday gift that combines design, animation, and storytelling into a memorable experience.

Instead of sending a simple greeting, the goal is to create something that feels personal, interactive, and unforgettable.
